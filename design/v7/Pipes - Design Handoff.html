System · 04

Status vocabulary

One unified icon set — a solid colour circle with a white symbol — applied everywhere, so the meaning is universal. The word lives in a hover title. A broken default branch is the headline state: red, with an alarm strip.

Reference · key

Glossary

Plain-language meaning of the terms used across the surfaces.

Default branch main / trunk
A repo’s primary branch. A failure here is the headline alarm — loud and pinned.
Ref
The branch or tag a pipeline ran against.
Pipeline / run
One execution of CI for a ref. A row shows the latest run per ref.
Job
A step within a run. Failures deep-link straight to the failed job’s log.
PR / MR
A proposed change (pull request / merge request). Its checks show in red but stay calm — not the loud main alarm.
Owner
The account or org repos are grouped under (e.g. feedmypixel). Tap it to open on the provider.
Connection
A GitHub or GitLab account + read-only token Pipes polls. The provider is auto-detected from the host.
Watched repo
A repository you’ve ticked for Pipes to monitor.
Poll interval
How often Pipes checks for new results (0.5 min minimum).
Transition
A change in state between polls. Notifications fire only on transitions — re-polling the same failure stays silent.

System · 05

Behaviour — straight to the point

A click lands on the exact run — never the repo.

Every row opens the specific pipeline/run in a new tab, and a failure goes deeper still — straight to the failed job’s log, scrolled to the failure. No landing on a pipelines list, no hunting. Browsing the rest of a repo is something people do themselves — out of scope for Pipes.

● Status, succinctly

Icons carry the state; the word is in a hover title so rows stay scannable and dense. No text labels cluttering the list.

● Loud only for main

A broken default branch gets the red alarm strip + pin. A failing PR/MR is shown in red but stays calm (amber note, no klaxon) — see the “Main green · PR/MR failing” popup state.

Surface · 07

Popup · 380px, auto-height → scroll

The quick glance. Repos grouped by owner, sorted A–Z. Each row shows the default-branch run; other refs collapse underneath. An alarm strip appears when main is red. Five states below — including a green main with a failing PR/MR (calm, not loud).

Surface · 08

Side panel · 360px, full height

Stays open while you work. Same row component as the popup but denser, plus a sticky health summary (“failing · green · other”) and a subtle auto-refresh indicator.

Surface · 09

Notifications & badge

The whole point: be loud the moment main breaks, quiet otherwise. OS notifications fire only on state transitions (re-polling the same failure stays silent) and use the status colour so a failure is unmissable. The toolbar icon reflects overall status at a glance.

Surface · 10

Options · centred 720px column

Connections (with live token state), an add-connection form that validates and auto-detects the provider, a searchable repo picker, and settings. Forms follow the portal forms.md spec: label → hint → error → input order, fields implicit-required with a lowercase (optional) tag, inline errors above the input, and submit never disabled (block via validation, not greying out).
