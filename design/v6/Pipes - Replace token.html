Replace token

An expired PAT currently means delete + re-add, which drops every watched repo for that connection. This adds an in-place “Replace token” on the connection row. The account id stays the same, so watched repos, labels and cached repo lists survive. Below: a working prototype (panel → options), every state in light and dark, and the build notes.

Prototype

The work connection’s token is failing. Click Replace token in the panel banner to jump to that row in Options with the edit already open and the field focused. Replace it and the banner clears.

Tokens to try: anything → valid · contains bad → HTTP 401 · contains other → belongs to a different account · empty → FormSummary. Esc cancels. Reset prototype

1 · The trigger on a connection row

Replace token is a key icon button next to delete, the same 30px size as the bin, with the label “Replace token for {label}” and the house use:tooltip (hover or focus; hover it here). On a healthy row it’s as quiet as the bin. When the token is failing, the row changes in four places at once: red dot, red inset edge (same treatment as a failing repo head in the panel), token rejected in place of the tick, and a one-line note saying what broke and what’s paused. The key itself stays neutral in both states.

2 · Inline edit

The row expands in place (one row open at a time). The form follows the existing Add-a-connection rules: Validate writes to the field’s below line; Save runs the same validation and reports server failures in a Banner at the top; client errors use FormSummary + field error. Nothing is disabled except Save while in flight.

3 · Panel banner

Today the whole strip is one button that opens Settings. A link can’t live inside a button, so for auth failures (401/403) the strip becomes a status region with its own Replace token control on the right; it wraps under the message at narrow widths. Other connection problems (network, 5xx) keep today’s whole-strip “open settings” behaviour. Message copy is unchanged. The outline triangle becomes the solid warning triangle from the new message icon set (section 4).

4 · Message icons

Options and the banners used outline Lucide glyphs while the panel uses solid status circles. This set brings them in line: same geometry as StatusIcon (solid fill, white glyph at 66% of the size, 3px round strokes). Warning keeps a triangle so it doesn’t rely on colour alone. Shown at 30 / 20 / 16px.

Build notes

Keep the account id

Replace writes token (and user) onto the existing Account in place. watchedRepos[].accountId stays valid, so nothing is lost. On success: clear failedRepos[id], run loadRepos(account), and ask the worker to poll now so the panel banner clears without waiting a cycle.

Same-account check

Needs Account.user, captured from validateToken().user at add time. Accounts saved before this ship have no user: skip the check, hide the “Must sign in as” hint, and record user on the first successful replace.

Deep link from the panel

Open or focus options/index.html#replace=<accountId>. On load (and on hashchange if the tab was already open): open that row’s edit, scroll it into view with window.scrollTo, focus the field, run the 1.4s highlight (none under reduced motion), then clear the hash.

Copy

  • Trigger: Replace token
  • Row: token rejected · “GitHub returned HTTP 401. 4 watched repos are paused until you replace the token.”
  • Field: New personal access token
  • Save: Save token / Saving token…
  • Mismatch: “It signs in as @x, not @y.”
  • Toast: Token replaced · “work is watching 4 repos again”

Keyboard + AT

  • Trigger has aria-expanded + aria-controls → the form.
  • Form has aria-label="Replace token for work".
  • Esc inside the form = Cancel; focus returns to the trigger after Cancel or Save.
  • below is aria-live="polite"; Banner err and FormSummary are role="alert".
  • Panel action is a real <button> named “Replace token for work”.

Contrast (AA)

  • New failing-row text uses --alarm-ink (light ≈ 5.5:1), not --failed.
  • Panel banner: amber --pending text on --pending-bg is ≈ 2:1 in light. The new strip uses --text for copy and action, with the icon in --pending.
  • Existing, out of scope but worth a ticket: --failed on --failed-bg (field error, Banner, FormSummary) and --success “token saved” are under 4.5:1 in light.
