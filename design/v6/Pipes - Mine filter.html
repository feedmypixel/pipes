The “Mine” scope filter

A new binary scope axis (everyone ↔ just me) for the side panel / popup filter row. It must read as distinct from the multi-select status chips, survive wrapping at ~320px, and use only existing tokens. Below: the recommendation in the real cluster (light + dark), the A/B/C comparison, and the build spec.

Recommendation: Treatment A — segmented control, leading the filters row, label “All | Mine”.

Recommended — in the real cluster

The segment sits at the head of the .filters row with a right-hand divider (mirroring how toggle-all uses a left divider). A segmented control is inherently a pick-one shape — joined, no gaps — so it never reads as an eighth status pill. A leading user-round glyph signals the authorship axis. Selected fill

Active segment uses --control-on / --control-on-ink / --control-on-edge — the exact filled-control tokens the status chips and sort use. No new colour.

Focus

focus-visible ring is --brand (Pixel Blue), inset so it reads inside the joined control. Arrow-key roving + Enter/Space; role="group", each segment aria-pressed.

Wrapping

The control is flex:none and anchors top-left; the status .pills wrap as a unit after the divider. Scope never splits, status never crowds it.

Motion / AA

No transition needed (instant state). Contrast on fill ≥ AA in both schemes; hit target ≥ 24px tall via --space-3xs padding matching the chips.

Why A over B and C

All three were mocked in the cluster. A wins on the brief’s central requirement — reading as a different axis — while staying compact.

The four decisions

1 · Treatment

A — segmented control, leading the .filters row, divided from the status pills.

2 · Label

“All | Mine”. “Mine” is the one word true for both PRs and MRs. “My PRs” breaks on GitLab; “Owned by me” / “Just mine” wrap. Off-state names the other half explicitly: “All”.

3 · Count

Silent on the control. At 320px a count crowds the row and fights the status chips. Reassurance already lives in the list (and the owner-group count). Optional: a muted Mine · 3 only if width allows — shown as a variant below.

4 · Empty

Leave as-is. Filter on + you own nothing → main shows alone, which is correct: “is main broken?” isn’t author-scoped. A quiet one-line no open PRs of yours is optional, not needed.

Optional — count variant

If you do want the hidden-count affordance, keep it on the active segment as a muted suffix, not a separate badge. Shown here only when “Mine” is active and width allows.
